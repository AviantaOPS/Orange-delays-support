ORANGE DELAYS — GITHUB PAGES SETUP

1. Open privacy.html and replace every [CONFIRM: ...] section with truthful details about the released app. Do not publish the draft policy unchanged.
2. Check that the support email in index.html and privacy.html is the email you want to publish publicly.
3. On GitHub, create a PUBLIC repository named orange-delays-support.
4. Upload index.html, privacy.html and style.css to the repository root (README.txt is optional).
5. Go to repository Settings > Pages > Build and deployment > Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for GitHub Pages deployment and open the public URLs to verify they work.
8. App Store Connect Support URL:
   https://YOUR-GITHUB-USERNAME.github.io/orange-delays-support/
9. App Store Connect Privacy Policy URL:
   https://YOUR-GITHUB-USERNAME.github.io/orange-delays-support/privacy.html

Replace YOUR-GITHUB-USERNAME with your actual GitHub account name.
These URLs are examples until the site has been published.
